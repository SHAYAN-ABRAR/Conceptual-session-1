# The Cat — HTML & CSS Fundamentals

A small single-page site about cats, built during a web-development concept session to practice core **HTML and CSS** techniques.

## Techniques Practiced

- **`clip-path` hero:** a full-height background image cut into a V-shape with `polygon()`
- **Typography:** Google Fonts (Lato, Roboto Condensed), plus heavy `letter-spacing` and `word-spacing` for the headline
- **Gradient cards:** `linear-gradient(45deg, pink, blueviolet)` section backgrounds with dotted-border headings
- **Flexbox gallery:** a "Types of Cats" image row
- **Background control:** `background-size: cover` and `background-position`
- **Custom favicon** loaded from Icons8
